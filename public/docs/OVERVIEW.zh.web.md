# BugIt QA Agent：概览

> **翻译说明。** 本文档由机器翻译生成，未经母语者审校。以英文版本为准：如有出入，以英文文本为准。如需最准确、最新的表述，请参阅英文文档。

BugIt 是一款商用的 VS Code Copilot 代理，可将零散的测试记录转化为规范一致的缺陷报告。它先在你的工作区中本地起草，只有在你预览并确认之后，才会写入所连接的服务。

## 核心工作流

- 采集粗略的复现记录、日志、截图以及预期行为。
- 起草一份结构化报告，包含标题、严重程度、环境、复现步骤和证据。
- 在所连接的跟踪系统中搜索可能存在的重复项。
- 在执行任何外部写入之前，预览并确认目标位置与最终内容。
- 在缺陷修复经过复测后，补充验证性备注。

## 隐私与掌控

- BugIt 不会向 Taskivator 发送任何产品分析数据或工单遥测数据。
- 你所连接的 AI 提供方及已启用的集成，仅处理你选择发送给它们的内容。
- 许可与更新请求仅使用许可数据和一个单向的设备标识符，而不涉及工单内容。
- 试运行模式可防止随附的 Python 辅助工具执行写入，但你仍须审查外部的 MCP 操作。
- 配置文件中绝不能包含任何凭据值。

## 集成层级

- 使用你在自己账户中创建的凭据提交；BugIt 会在保存连接前，将该凭据对你选定的目标进行验证：Jira Cloud、Azure DevOps、GitHub Issues、GitLab Issues、Bugzilla、YouTrack、Linear、Shortcut、ClickUp、Asana 和 Trello。全部十一个，各自通过其自身的 API 提交。
- 引导式知识库来源，只读：通过 Atlassian Rovo MCP 连接的 Confluence Cloud（浏览器登录）。Sentry 和 Notion 在通过实时检查前仍为实验性。
- 仅提供配置指引：由所在组织提供的兼容服务器，用于崩溃工具、测试管理、通讯和知识服务。
- 自动化设置不支持：S3、Google Drive 与 Azure Blob 存储连接器。
