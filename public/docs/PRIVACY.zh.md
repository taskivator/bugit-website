# 隐私政策 — BugIt

Copyright (c) 2026 Taskivator. All Rights Reserved.

**最后更新：2026年8月1日**

本政策说明当您使用 BugIt 网站（bugit.dev）、BugIt Portal（账户、购买及许可证管理）
以及 BugIt QA Agent 软件时，会处理哪些个人数据，以及您所拥有的选择与权利。本政策以
通俗语言撰写，旨在如实反映产品的实际运作方式。

## 谁对您的数据负责

BugIt 以商号 **Taskivator / BugIt** 运营。所有隐私相关问题与请求的运营联系方式为
**support@bugit.dev**。

**所有者已选择不公开用于识别控制者（数据控制者）的个人身份信息。这仍属于一项已被接受
的法律合规风险，且未获得外部法律审批。** 仅凭商号并不能满足识别数据控制者的法律要求；
因此，该项要求**不**被视为已由本政策满足。基于此原因，注册的控制者身份信息不予公开；
在法律赋予您获取此类信息之权利的情形下，您可通过 support@bugit.dev 提出请求。

## 简要版

- **QA Agent 软件在您的设备上运行。** 您的错误报告、规格说明、术语表、屏幕截图、
  代码、设置及工单**不会**发送给 Taskivator。
- 为运营您的账户、购买、许可证及支持，**网站与 Portal** 会借助下列服务提供商处理一组
  有限的个人数据（您的邮箱、购买记录、许可证与设备激活，以及支持消息）。
- 我们**不会**出售您的个人数据。广告衡量**默认关闭**，仅在获得您的同意后才会运行。

## QA Agent 软件向 Taskivator 发送的内容

BugIt 使用**基于浏览器的激活**——您在浏览器中登录 BugIt Portal 并批准该设备；**没有
需要输入、粘贴或存储的许可证密钥**。软件从您的设备仅发送许可证/更新数据：

- 来自该 Portal 登录的**已签名的使用权/设备激活记录**（以便对您的设备进行授权和重新
  验证）以及应用版本，
- 一个**匿名的、经单向哈希处理的设备指纹**——一个由基本机器属性派生而来的 16 位字符
  哈希值；它无法被逆推以识别您本人或您的硬件，以及
- **仅当您在首次运行设置时进行了设置**，您所选择的一个简短的设备/席位标签，以便区分
  Team 账户下各设备的授权。它从不要求为真实信息，也从不进行验证。如果您未进行设置，
  则不会发送任何内容。

这些内容仅发送至 Taskivator 许可证服务，用于激活/验证您的席位以及检查是否有更新版本
可用。

## 完全保留在您设备上的内容

- 您的规格说明、术语表、团队风格以及习得的更正
- 您的 `config.json` 及本地项目文件
- 您的 API 令牌（保存在您操作系统的凭据库中——绝不会存入文件，也绝不会传输给
  Taskivator）

以上内容均不会被传输到任何地方。

## 仅发送至*您*所连接服务的内容

为撰写和提交工单，您的报告文本会被发送至您所使用的 AI 模型（GitHub Copilot，或您自己
的 OpenAI/Anthropic 密钥）以及您提交到的 tracker（如 Jira 或 Azure DevOps）。这些是
**您**自行选择并连接的 AI 与工具——由于 Taskivator 并非这些服务的控制者，相关内容
绝不会经由 Taskivator 转发、复制到 Taskivator，或被 Taskivator 查看。仅提交所需的
元数据（问题 ID/URL，以及您所批准的内容）会与它们进行交换。

## 服务提供商（处理者）与国际传输

我们使用以下提供商来运营 BugIt。每家提供商仅为向我们提供其服务而处理个人数据。当个人
数据被传输至 EEA/英国境外时，我们依据提供商的数据处理附录，并在适用情况下依据标准合同
条款（或等效的传输机制）。

| 提供商 | 目的 | 数据类别 | 可能的处理地点 | 传输依据 | 保留/删除 |
|--------|------|----------|----------------|----------|-----------|
| **Supabase** | 数据库 + 认证（账户、使用权、设备、订单、审计日志） | 账户、使用权、设备、订单、日志数据 | 美国和/或欧盟（项目区域） | 数据处理附录 + 适用情况下的标准合同条款 | 在您的账户处于活动状态期间保留；不再需要时删除或匿名化（见保留表） |
| **Stripe** | 支付处理、退款、争议、税额计算 | 支付、账单、交易数据 | 美国 + 全球 | 数据处理附录 + 标准合同条款 | 由 Stripe 依据其政策及法律/会计要求保留 |
| **Cloudflare** | 网站分发、安全、无 Cookie 网页分析 | 网络/技术数据；聚合分析 | 全球边缘网络 | 数据处理附录 + 标准合同条款 | 短期保留；分析为聚合且不使用 Cookie |
| **Vercel** | 托管网站/Portal 应用 | 请求/技术数据 | 美国 + 全球 | 数据处理附录 + 标准合同条款 | 运营日志短期保留 |
| **Resend** | 发送事务性电子邮件（收据、许可证、支持） | 电子邮件地址、消息元数据 | 美国 | 数据处理附录 + 标准合同条款 | 依据提供商政策保留；投递日志短期保留 |
| **Google Ads** | 广告衡量（仅在获得同意时） | 购买金额、币种、不具识别性的订单参考 | 美国 + 全球 | 数据处理附录 + 标准合同条款 | 仅在获得同意时；不共享任何错误内容或卡片数据 |

我们**不会**出售个人数据，广告衡量也绝不会收到您的错误报告、BugIt 软件的内容或支付卡
详情。

## 我们保留数据的时长（保留）

在法律未规定期限的情况下，我们仅在实现目的所需的期间内保留数据，之后即予以删除或匿名化。

| 类别 | 保留 |
|------|------|
| 账户 | 在活动期间；账户删除后予以删除/匿名化（受法定保留义务约束） |
| 认证记录 | 在账户处于活动状态期间 |
| 使用权/许可证 | 在许可证期限内，以及其后为支持和争议目的的有限期间 |
| 设备/激活 | 在使用权处于活动状态期间；在您移除设备或许可证结束时释放 |
| Team 成员资格/邀请 | 在 Team 许可证处于活动状态期间；邀请会过期 |
| 支付 | 在许可证期限内，再加上会计/税务所需的期间 |
| 退款/争议/拒付 | 在处理并证明所需的期间内，再加上会计期间 |
| 税务/会计记录 | 按适用税法的要求（例如最长 7 年） |
| 安全日志 | 足以用于安全和滥用侦测的有限期间 |
| 管理员审计日志 | 作为完整性记录保留有限期间 |
| 支持往来信息 | 在为您提供支持所需的期间内，以及其后的有限期间 |
| 营销同意 | 在同意持续期间，以及其后作为证明 |
| 同意撤回 | 作为已尊重某项选择的证明予以保留 |
| 已删除账户的备份 | 删除后，在常规备份轮换范围内从例行备份中清除 |

## Cookie 与广告

网站仅使用运行所必需的 Cookie。非必需的（广告）Cookie **默认关闭**，仅在您通过 Cookie
横幅或 **Cookie 偏好设置**选择启用时才会加载。我们使用 Cloudflare Web Analytics，它
不使用 Cookie，也不会跨网站跟踪您。您可以随时更改或撤回您的选择。

## 您的权利

视您的居住地而定（例如依据欧盟/英国 GDPR 或日本的 APPI（个人信息保护法）），您可能享有
以下权利：

- **访问**我们所持有的关于您的个人数据
- **更正**不准确的数据
- **删除**您的数据（及您的账户）
- **限制**或**反对**某些处理
- **可携性**——以可携格式接收某些数据
- 随时**撤回同意**（例如广告衡量），且不影响此前的合法处理

如需行使上述任一权利，请使用您的账户地址向 **support@bugit.dev** 发送电子邮件。您也
可以**删除您的账户**以移除您的数据（但受我们依法必须保留的记录约束，例如税务记录）。
我们将在适用法律所要求的期限内予以回复。

**投诉。** 如果您位于 EEA，您可以向您当地的数据保护机构投诉；在英国，可向 Information
Commissioner's Office（ico.org.uk）投诉；在日本，可向个人信息保护委员会（ppc.go.jp）
投诉。我们希望能有机会先在 support@bugit.dev 处理您的关切。
