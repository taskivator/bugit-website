本政策说明当您使用 BugIt 网站（bugit.dev）、BugIt Portal（账户、购买及许可证管理）以及 BugIt QA Agent 软件时，我们会处理哪些个人数据，以及您拥有哪些选择与权利。

## 运营方与隐私联系方式

BugIt 以商号 Taskivator 运营。有关隐私的问题、个人数据请求，以及索取运营方法定名称和营业联系方式的请求，均可发送至 [support@bugit.dev](mailto:support@bugit.dev)。所索取的运营方信息将不迟延地提供。

## 摘要

- BugIt 软件在您自己的计算机上运行。您的缺陷报告、规格说明、术语表、屏幕截图、代码、设置和工单不会传输给 Taskivator。
- 为运行您的账户、购买、许可证和支持，网站与 Portal 会处理有限的个人数据。
- 我们不出售个人数据。广告衡量默认关闭，只有在您开启后才会运行。

## BugIt 软件向我们发送的信息

BugIt 通过浏览器激活：您登录 BugIt Portal 并批准该设备。没有需要输入或保存的许可证密钥。软件从您的设备只发送运行许可证所必需的信息：

- 由该次 Portal 登录生成的已签名授权与设备激活记录，用于授权您的设备并在此后再次校验，以及应用版本；
- 一个化名设备标识符，用于许可证激活、设备数量限制和防欺诈；以及
- 一个简短的设备或席位名称，仅在您于初始设置时选择填写的情况下发送，用于区分 Team 账户下的各设备。该项为可选，且不会被核实。

这些信息仅发送至 Taskivator 的许可证服务，用于激活和校验您的席位，以及检查是否有更新版本。

## 保留在您设备上的信息

- 您的规格说明、术语表、写作风格与已学习的更正
- 您的 `config.json` 及本地项目文件
- 您的 API 令牌，保存在操作系统的凭据存储中

这些信息不会传输给 Taskivator。

## 发送至您所连接服务的信息

为撰写并提交工单，您的报告正文会发送至您所使用的 AI 提供方（GitHub Copilot，或您自己的 OpenAI 或 Anthropic 密钥），以及您提交到的缺陷跟踪工具，例如 Jira 或 Azure DevOps。这些是由您选择并连接的服务，发送至这些服务的信息不会经由 Taskivator 中转，也不会复制给 Taskivator。所连接的 AI 提供方和问题跟踪工具依据其各自的条款和隐私政策处理信息，建议您在连接某项服务前先行查阅。

## 我们为网站与 Portal 处理的个人数据

- **账户与登录信息**，包括您的电子邮件地址，用于创建并保护您的账户
- **购买与订单记录**，包括收据和税务记录
- **支付数据**，由我们的支付服务商处理。我们不存储完整的卡号。
- **授权与许可证**，用于交付并校验您所购买的内容
- **设备激活信息**，包括化名设备标识符、您设置的名称，以及操作系统和应用版本，用于实施席位与设备数量限制，并便于您自行管理设备
- **Team 成员资格与邀请**，用于提供 Team 方案
- **退款、争议与拒付**记录（如发生）
- **支持往来信息**，用于答复您的咨询
- **安全与管理记录**，用于发现滥用行为并保留审计轨迹
- 您保存的 Jira、Azure DevOps 等**跟踪工具连接设置**。我们保存连接设置，不保存这些工具中的内容。
- 您对 Cookie 和广告衡量的**同意选择**（包括撤回），以及在特定市场要求时于结账环节记录的确认

我们使用这些数据来提供并支持您所购买的产品、收取款项并履行税务与会计义务、保障账户与许可证安全，以及在您同意的前提下衡量广告效果。视您所在地区而定，法律依据通常为履行与您的合同、遵守法定义务、我们在保障服务安全方面的正当利益，或您的同意。

## 服务提供商

我们使用服务提供商完成身份验证与托管、支付处理、交易邮件、网站分发与安全，以及基于同意的广告衡量。这些提供商仅处理为我们提供服务所必需的信息，且不得将其用于自身目的。

主要提供商为 Supabase（账户与数据库）、Stripe（支付、退款与争议）、Vercel（Portal 托管）、Cloudflare（网站分发、安全与无 Cookie 分析）、Resend（交易邮件）以及 Google（广告衡量，仅在您同意时）。

其中部分提供商在您所在国家/地区以外运营，包括美国。当个人数据发生跨境传输时，我们依据该提供商提供的数据保护条款。

广告衡量绝不会收到您的缺陷报告、BugIt 软件的内容或您的支付卡信息。

## 数据保留期限

我们仅在实现收集目的所需的期间内保留个人数据，之后即予删除或匿名化。具体而言：

- 账户、许可证和设备记录在您的账户与许可证有效期间保留，并在此后保留有限期间，以便处理支持与争议事项。
- 支付、税务与会计记录按法律规定的期限保留。
- 支持往来信息、安全记录和同意记录保留有限期间；同意记录作为您的选择已获尊重的证明予以保存。

若您删除账户，除我们依法必须保留的记录外，我们将删除或匿名化您的数据。

## Cookie 与广告

本网站使用运行所必需的 Cookie。广告 Cookie 默认关闭，仅在您通过 Cookie 提示条或 **Cookie 偏好设置**开启后才会加载。我们使用 Cloudflare Web Analytics 了解网站整体性能，该服务不使用 Cookie，也不会跨站点追踪您。您可以随时更改或撤回您的选择。

网站上的视频嵌入自 YouTube。在您按下播放之前，不会向 YouTube 发出任何请求，在此之前页面只显示由我们提供的图片。当您按下播放时，播放器会从 YouTube 的隐私增强主机 youtube-nocookie.com 加载，Google 会收到您的 IP 地址和所选视频以便播放。如果您从不按下播放，视频板块不会向 Google 发送任何内容。

## 您的权利

视您所在地区而定，例如根据欧盟或英国 GDPR、日本《个人信息保护法》，您可能有权访问我们持有的与您有关的个人数据，更正、删除这些数据，限制或反对特定处理，以可携格式获取数据，并随时撤回同意，且不影响撤回前已进行的处理。

如需行使上述任一权利，请从您的账户邮箱发送邮件至 [support@bugit.dev](mailto:support@bugit.dev)。您也可以在控制面板中删除账户。我们将在适用法律规定的期限内答复。

如您对处理结果不满意，可向数据保护机构投诉：在欧洲经济区，向您当地的监管机构；在英国，向信息专员办公室（ico.org.uk）；在日本，向个人信息保护委员会（ppc.go.jp）。我们也希望能先有机会为您解决问题。
