本ページは、BugIt の販売に関する特定商取引法（通信販売）に基づく表記です。

## 販売事業者情報

販売事業者の氏名、住所および電話番号は、請求があり次第、購入のお申込み前に遅滞なく開示いたします。開示をご希望の場合は、[support@bugit.dev](mailto:support@bugit.dev) までご連絡ください。

BugIt は、屋号 Taskivator のもとで販売しています。

## お問い合わせ

メール：[support@bugit.dev](mailto:support@bugit.dev)

ご購入、提供、ライセンス、返金、サポートに関するお問い合わせ窓口です。サポートは英語で提供いたします。

## 商品および販売価格

BugIt は、Visual Studio Code 上で動作し、QA チームがバグレポートを作成、確認し、トラッカーへ登録することを支援するダウンロード版ソフトウェアです。

- BugIt Solo：US$39.99
- BugIt Team：US$199.00

価格は米ドル表示です。実際にご請求する金額は、ご購入時にチェックアウト画面に表示される金額です。

## 商品代金以外に必要な料金および税

チェックアウト画面に表示される金額が、商品に対するご請求総額です。当社が徴収すべき税がある場合は、お支払い前にチェックアウト画面に表示いたします。インターネット接続料およびお客様がご契約中の通信事業者等にお支払いになる料金は、お客様のご負担となります。継続課金その他の費用はございません。

## お支払い方法およびお支払い時期

決済は Stripe が処理いたします。ご購入時に Stripe Checkout が提供するカードその他のお支払い方法をご利用いただけます。お支払いは、ご購入時に全額をお願いしております。BugIt は買い切り商品であり、サブスクリプション、自動更新、購入後の追加請求はございません。

## 提供時期

提供はデジタル形式です。決済の確認後ただちに、ダウンロードおよび BugIt Portal でのブラウザによるアクティベーションを、お客様のアカウントでご利用いただけます。

## ライセンス期間および提供範囲

- ご購入により、ご購入日から 1 年間有効なライセンスを付与いたします。自動更新はいたしません。期間が満了するとライセンスは失効し、継続してご利用いただくには新たなご購入が必要です。
- 期間中は、365 日間のアップデートおよびライセンスサービスが含まれます。
- BugIt Solo は、お一人のお客様が同時に 1 台のデバイスでご利用いただけます。
- BugIt Team は、最大 5 名までご利用いただけます。各メンバーが自分の BugIt アカウントを持ち、自分のデバイスをアクティベーションし、BugIt Portal で一元管理いたします。

## 動作環境

BugIt は Visual Studio Code 上で動作し、お客様にご用意いただく AI プロバイダー（GitHub Copilot、またはお客様ご自身の OpenAI もしくは Anthropic のキー）と、対応バージョンの Python を必要とします。トラッカーへの登録には、お客様ご自身のトラッカーアカウントで作成して BugIt に入力する API トークンを使用いたします。アクティベーションおよび定期的なライセンス確認のため、インターネット接続が必要です。確認と確認の間は、最大 72 時間オフラインでご利用いただけます。

## キャンセルおよび返金

BugIt では、その規約に従い、任意の 7 日間返金ポリシーをご用意しております。詳しくは[返金ポリシー](#/docs/refund)をご覧ください。

デジタル形式の提供はお客様のご請求により直ちに開始されるため、提供開始後は、法定のキャンセル権または撤回権に影響が生じる場合がございます。これに該当する場合は、お支払い前にチェックアウト画面でご確認をお願いしております。

本表記は、法令上排除することができない消費者の権利を制限するものではありません。

## 契約不適合または不良の場合

デジタルコンテンツに不良がある場合、表示と異なる場合、またはご購入の内容に適合しない場合は、[support@bugit.dev](mailto:support@bugit.dev) までご連絡ください。契約不適合または不良のデジタルコンテンツに関するお客様の法律上の権利は影響を受けません。

## カスタマーサポート

[support@bugit.dev](mailto:support@bugit.dev) までメールでご連絡ください。サポートは英語で提供いたします。機密のソースコード、顧客データ、非公開のチケット、シークレット情報は記載なさらないようお願いいたします。
