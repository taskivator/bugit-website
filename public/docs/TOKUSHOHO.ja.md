# 特定商取引法に基づく表記

**最終更新日：2026年8月1日**

本ページは、BugIt の販売に関する特定商取引法（通信販売）に基づく表記です。

## 販売事業者の表示に関する重要なお知らせ

一部の販売事業者の識別情報は、事業者の判断により公開していません。お問い合わせは、
公開しているサポート用メールアドレスまでお願いいたします。本表記は、適用されるすべての
法定の販売事業者識別要件を満たすものとして認証されたものではありません。

上記の理由により、**販売事業者名・所在地・電話番号は公開していません**。これらの欄には、
体裁を整えるための代替情報やダミー情報を記載せず、「非公開」と表示しています。

## 表記事項

**販売ブランド名：** Taskivator ／ BugIt

**販売事業者名：** 非公開（上記のお知らせをご参照ください）。

**所在地：** 非公開（上記のお知らせをご参照ください）。サポート用メールアドレスへのご請求により
遅滞なく開示します。

**電話番号：** 非公開（上記のお知らせをご参照ください）。お問い合わせはメールにて承ります。
連絡可能な電話番号は、サポート用メールアドレスへのご請求により遅滞なく開示します。

**連絡先・サポート：** support@bugit.dev — ご購入・提供・返金・サポートに関するすべての
お問い合わせ窓口です。

**販売価格：**
- BugIt Solo — 導入価格 US$39.99（通常価格 US$59.99）。
- BugIt Team — 導入価格 US$199（通常価格 US$249.99）。

価格は米ドル表示です。実際にお支払いいただく金額は、購入時にチェックアウト画面に表示される
金額です。

**商品代金以外に必要な料金：** お客様の地域で必要となる消費税・付加価値税（VAT）・
物品サービス税（GST）は、お支払い前にチェックアウト画面で計算・表示されます。インターネット
接続料・通信料はお客様のご負担となります。その他の継続課金や隠れた費用はありません。

**お支払い方法：** 決済は Stripe が処理します。購入時に Stripe Checkout が提供するカード等の
お支払い方法をご利用いただけます。

**お支払い時期：** 購入時に全額をお支払いいただきます。BugIt は買い切り（一回限りの購入）で
あり、サブスクリプションや自動更新はなく、購入後に自動で課金されることはありません。

**引渡し・提供の時期：** 提供はデジタルで即時です。決済完了後ただちに、ダウンロードおよび
ブラウザ経由の Portal でのアクティベーションがご利用可能になります。お客様のご請求により提供が
即時に開始されるため、下記のキャンセルに関する条件をご確認ください。

**購入内容（期間と範囲）：**
- 買い切りで、初回アクティベーション時に開始する**1年間のライセンス**を付与します。
  **自動更新はされません。** 期間が満了するとライセンスは失効し、継続してご利用いただくには
  新しいライセンスのご購入（任意）が必要です。
- 期間中の**365日間のアップデート**およびライセンス・アクティベーションサービスを含みます。
- **Solo：** 同時に**1台のデバイス**（1ユーザー）でご利用いただけます。
- **Team：** **最大5名**まで。各メンバーが自分の BugIt アカウントと自分のデバイス
  アクティベーションを持ち、Portal で一元管理されます。

**動作環境：** BugIt は、サポート対象の OS 上で Visual Studio Code および GitHub Copilot
と組み合わせて動作します。アクティベーションおよび定期的なライセンス確認のためにインターネット
接続が必要です（確認と確認の間は最大72時間オフラインで動作します）。

**返品・キャンセル・返金：**
- BugIt は、その規約に従い**任意の7日間返金ポリシー**を提供します（返金ポリシーをご参照
  ください）。
- 法定のキャンセル権・撤回権がある地域（例：EU/EEA、英国）の消費者の場合、即時のデジタル
  提供をご請求のうえ受領された時点で、その権利が縮減または消滅することがあります。この点は、
  お支払い前にチェックアウトで確認をお願いしています。
- 消費者としての**法定の権利**は、本ページや任意の返金ポリシーによって排除・制限されません。

**不良品・契約不適合の場合：** デジタルコンテンツに不良、表示との相違、または契約不適合が
ある場合は、support@bugit.dev までご連絡ください。不良または契約不適合のデジタルコンテンツに
関するお客様の法定の権利は影響を受けません。

**サポート手順：** support@bugit.dev までメールでご連絡ください。サポートは英語で提供されます。
