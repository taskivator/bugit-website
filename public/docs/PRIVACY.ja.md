## 要点

- BugIt ソフトウェアは、お客様ご自身のマシン上で動作します。バグレポート、仕様、用語集、スクリーンショット、コード、設定、チケットが Taskivator に送信されることはありません。
- アカウント、ご購入、ライセンス、サポートを運用するため、ウェブサイトおよび Portal では限られた範囲の個人データを取り扱います。
- 当社は個人データを販売いたしません。広告効果測定は既定でオフであり、お客様がオンにされた場合にのみ動作します。

## BugIt ソフトウェアが当社に送信する情報

BugIt はブラウザ経由でアクティベーションを行います。お客様が BugIt Portal にサインインし、デバイスを承認します。入力や保存が必要なライセンスキーはありません。お客様のデバイスからは、ライセンスの運用に必要な情報のみを送信します。

- Portal でのサインインにより発行された、署名付きのエンタイトルメントおよびデバイスアクティベーション記録（デバイスの認可と、その後の再確認のために使用します）、ならびにアプリのバージョン
- ライセンスのアクティベーション、デバイス数の制限、不正利用の防止のために使用する仮名化されたデバイス識別子
- セットアップ時にお客様が設定を選ばれた場合に限り、Team アカウントのデバイスを区別するための短いデバイス名またはシート名。任意であり、内容の検証は行いません。

これらは、シートのアクティベーションと確認、および新しいバージョンの有無の確認のために、Taskivator のライセンスサービスにのみ送信されます。

## お客様のデバイス内に留まる情報

- 仕様、用語集、ハウススタイル、学習した修正内容
- `config.json` およびローカルのプロジェクトファイル
- API トークン（オペレーティングシステムの資格情報ストアに保管されます）

これらの情報が Taskivator に送信されることはありません。

## お客様が接続したサービスに送信される情報

チケットを作成し登録するために、レポート本文は、お客様がご利用の AI プロバイダー（GitHub Copilot、またはお客様ご自身の OpenAI もしくは Anthropic のキー）と、Jira や Azure DevOps などの登録先トラッカーに送信されます。これらはお客様が選択し接続されたサービスであり、そこへ送信される情報が Taskivator を経由したり、Taskivator に複製されたりすることはありません。接続先の AI プロバイダーおよび課題管理ツールは、それぞれの利用規約およびプライバシーポリシーに基づいて情報を取り扱いますので、接続前にご確認ください。

## ウェブサイトおよび Portal で取り扱う個人データ

- **アカウントおよびサインインに関する情報**（メールアドレスを含む）。アカウントの作成と保護のために使用します。
- **ご購入および注文の記録**（領収書、税務記録を含む）
- **決済情報**。決済代行事業者が取り扱います。当社がカード番号の全体を保管することはありません。
- **エンタイトルメントおよびライセンス**。ご購入内容の提供と確認のために使用します。
- **デバイスのアクティベーション情報**（仮名化されたデバイス識別子、お客様が設定された名称、オペレーティングシステム、アプリのバージョン）。シートおよびデバイス数の制限の運用と、お客様ご自身によるデバイス管理のために使用します。
- **Team のメンバーシップおよび招待**。Team プランの提供のために使用します。
- **返金、係争、チャージバック**に関する情報（発生した場合）
- **サポートに関するやり取り**。お問い合わせへの回答のために使用します。
- **セキュリティおよび管理上の記録**。不正利用の検知と監査証跡の保持のために使用します。
- Jira や Azure DevOps などの**トラッカーの接続設定**。接続設定を保管するものであり、それらのツール内のコンテンツを保管するものではありません。
- Cookie および広告効果測定に関する**同意の選択**（撤回を含む）、ならびに市場によって必要とされる場合にチェックアウトで記録される確認

これらのデータは、ご購入いただいた製品の提供とサポート、決済の受領と税務・会計上の義務の履行、アカウントとライセンスの保護、およびお客様の同意がある場合の広告効果測定のために使用します。お客様の居住地によりますが、法的根拠は通常、お客様との契約の履行、法的義務の遵守、サービスの安全確保に関する当社の正当な利益、またはお客様の同意です。

## サービスプロバイダー

当社は、認証およびホスティング、決済処理、取引メールの送信、ウェブサイトの配信とセキュリティ、ならびに同意に基づく広告効果測定のために、サービスプロバイダーを利用しています。これらのプロバイダーは、当社にサービスを提供するために必要な情報のみを取り扱い、自らの目的のために利用することは認められていません。

主なプロバイダーは、Supabase（アカウントおよびデータベース）、Stripe（決済、返金、係争）、Vercel（Portal のホスティング）、Cloudflare（ウェブサイトの配信、セキュリティ、Cookie を用いないアクセス解析）、Resend（取引メール）、および Google（広告効果測定。お客様の同意がある場合に限ります）です。

これらのプロバイダーの一部は、米国を含むお客様の国以外で事業を行っています。個人データが国境を越えて移転される場合、当社は当該プロバイダーが提供するデータ保護条項に依拠します。

広告効果測定が、お客様のバグレポート、BugIt ソフトウェアの内容、またはお支払いのカード情報を受け取ることはありません。

## データの保存期間

当社は、収集した目的のために必要な期間に限り個人データを保存し、その後は削除または匿名化します。実際には次のとおりです。

- アカウント、ライセンス、デバイスの記録は、アカウントおよびライセンスが有効な間、ならびにサポートや係争に対応するために必要な限られた期間、保存します。
- 決済、税務、会計に関する記録は、法令で定められた期間、保存します。
- サポートのやり取り、セキュリティ記録、同意の記録は限られた期間保存し、同意の記録はお客様の選択が尊重されたことの証跡として保存します。

アカウントを削除された場合、法令上保存が必要な記録を除き、お客様のデータを削除または匿名化します。

## Cookie と広告

本ウェブサイトは、サイトの動作に必要な Cookie を使用します。広告用 Cookie は既定でオフであり、Cookie バナーまたは **Cookie 設定**でお客様がオンにされた場合にのみ読み込まれます。サイト全体のパフォーマンス把握のために Cloudflare Web Analytics を使用しています。これは Cookie を使用せず、サイトをまたいでお客様を追跡することはありません。お客様の選択は、いつでも変更または撤回いただけます。

## お客様の権利

お客様の居住地によっては、たとえば EU または英国の GDPR や日本の個人情報保護法に基づき、当社が保有するお客様の個人データへのアクセス、訂正、削除、特定の取扱いの制限または異議申立て、可搬性のある形式での受領、および既に行われた取扱いに影響を与えることなくいつでも同意を撤回する権利を有する場合があります。

これらの権利を行使される場合は、アカウントにご登録のメールアドレスから [support@bugit.dev](mailto:support@bugit.dev) までご連絡ください。ダッシュボードからアカウントを削除することもできます。適用される法令が定める期間内にご回答いたします。

ご納得いただけない場合は、データ保護当局に申立てを行うことができます。EEA では各国の当局、英国では情報コミッショナー事務局（ico.org.uk）、日本では個人情報保護委員会（ppc.go.jp）です。まずは当社にご相談いただけますと幸いです。
