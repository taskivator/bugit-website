本ポリシーは、お客様が BugIt のウェブサイト（bugit.dev）、BugIt Portal（アカウント、
購入、およびライセンスの管理）、および BugIt QA Agent ソフトウェアをご利用になる際に、
どのような個人データが取り扱われるか、ならびにお客様が有する選択肢と権利について説明する

## お客様のデータについて責任を負う者

BugIt は商号 **Taskivator / BugIt** のもとで運営されています。プライバシーに関する
すべてのご質問およびご請求の運用上の連絡先は **support@bugit.dev** です。

**所有者は、管理者（データ管理者）を特定するための個人的な情報を公開しないことを選択して
います。これは受容された法令遵守上のリスクとして残っており、外部の法的な承認を受けていません。**
商号だけでは、データ管理者を特定するという法的義務を満たしません。したがって、その義務は
本ポリシーによって満たされているものとは**扱われません**。この理由により、登録された管理者
の身元に関する情報は公開されません。法律によりお客様がこれらを受け取る権利を有する場合は、
support@bugit.dev までご請求いただけます。

## 要約版

- **QA Agent ソフトウェアはお客様のマシン上で動作します。** お客様のバグレポート、仕様、
  用語集、スクリーンショット、コード、設定、およびチケットは、Taskivator に送信され**ません**。
- お客様のアカウント、購入、ライセンス、およびサポートを運用するために、**ウェブサイトおよび
  Portal** は、以下に記載するサービスプロバイダーを利用して、限定された個人データ（お客様の
  メールアドレス、購入記録、ライセンスおよびデバイスのアクティベーション、サポートメッセージ）
  を取り扱います。
- 当社はお客様の個人データを**販売しません**。広告計測は**既定でオフ**であり、お客様の同意が
  ある場合にのみ実行されます。

## QA Agent ソフトウェアが Taskivator に送信するもの

BugIt は**ブラウザベースのアクティベーション**を使用します。お客様はブラウザで BugIt Portal
にサインインしてデバイスを承認します。入力、貼り付け、または保存する**ライセンスキーはありません**。
お客様のデバイスから、本ソフトウェアはライセンス／更新データのみを送信します：

- その Portal サインインから得られる**署名済みのエンタイトルメント／デバイスアクティベーション
  記録**（お客様のデバイスを認可し再検証できるようにするため）、およびアプリのバージョン、
- **匿名の、一方向でハッシュ化されたデバイスフィンガープリント** — 基本的なマシン属性から
  導出される 16 文字のハッシュです。これを逆算して、お客様またはお客様のハードウェアを特定
  することはできません。そして
- **初回セットアップ時に設定した場合に限り**、Team アカウントのデバイス認可を区別できるように
  お客様が選んだ、短いデバイス／シートのラベル。実在するものである必要は一切なく、検証も
  行われません。設定しない場合、何も送信されません。

これらは Taskivator のライセンスサービスにのみ送信され、お客様のシートをアクティベート／検証し、
より新しいバージョンが利用可能かどうかを確認する目的にのみ使用されます。

## お客様のデバイスに完全にとどまるもの

- お客様の仕様、用語集、ハウススタイル、および学習された修正
- お客様の `config.json` およびローカルのプロジェクトファイル
- お客様の API トークン（OS の資格情報ストアに保管されます — ファイルに保存されることはなく、
  Taskivator に送信されることも決してありません）

これらのいずれも、どこにも送信されません。

## *お客様が*接続するサービスにのみ送信されるもの

チケットを作成して起票するために、お客様の報告テキストは、お客様が使用する AI モデル
（GitHub Copilot、またはお客様ご自身の OpenAI／Anthropic キー）、および起票先のトラッカー
（Jira や Azure DevOps など）に送信されます。これは**お客様**が選択し、接続した AI および
ツールであり、これらのサービスの管理者ではない Taskivator を経由したり、Taskivator に
コピーされたり、Taskivator に閲覧されたりすることは決してありません。起票に必要なメタデータ
（課題の ID／URL、およびお客様が承認した内容）のみがそれらとやり取りされます。

## サービスプロバイダー（処理者）と国際的なデータ移転

当社は BugIt を運用するために以下のプロバイダーを利用しています。各社は、当社にサービスを
提供する目的にのみ個人データを処理します。個人データが EEA／英国の外に移転される場合、当社は
プロバイダーのデータ処理契約（DPA）、および該当する場合には標準契約条項（または同等の移転
メカニズム）に依拠します。

| プロバイダー | 目的 | データの種類 | 処理場所（見込み） | 移転の根拠 | 保持／削除 |
|--------------|------|--------------|--------------------|------------|------------|
| **Supabase** | データベース＋認証（アカウント、エンタイトルメント、デバイス、注文、監査ログ） | アカウント、エンタイトルメント、デバイス、注文、ログのデータ | 米国および／または EU（プロジェクトのリージョン） | DPA＋該当する場合は標準契約条項 | お客様のアカウントが有効な間は保持；不要になった時点で削除または匿名化（保持の表を参照） |
| **Stripe** | 支払い処理、返金、紛争、税額計算 | 支払い、請求、取引のデータ | 米国＋グローバル | DPA＋標準契約条項 | Stripe が自社のポリシーおよび法的／会計上の要件に従って保持 |
| **Cloudflare** | ウェブサイトの配信、セキュリティ、Cookie 不使用のウェブ解析 | ネットワーク／技術データ；集計された解析データ | グローバルなエッジネットワーク | DPA＋標準契約条項 | 短期間；解析は集計されており Cookie を使用しません |
| **Vercel** | ウェブサイト／Portal アプリケーションのホスティング | リクエスト／技術データ | 米国＋グローバル | DPA＋標準契約条項 | 運用ログは短期間保持 |
| **Resend** | トランザクションメールの送信（領収書、ライセンス、サポート） | メールアドレス、メッセージのメタデータ | 米国 | DPA＋標準契約条項 | プロバイダーのポリシーに従って保持；配信ログは短期間 |
| **Google Ads** | 広告計測（同意がある場合のみ） | 購入金額、通貨、識別につながらない注文参照 | 米国＋グローバル | DPA＋標準契約条項 | 同意がある場合のみ；バグの内容やカードデータは共有されません |

当社は個人データを**販売せず**、広告計測がお客様のバグレポート、BugIt ソフトウェアの内容、
または支払いカードの詳細を受け取ることは決してありません。

## データの保持期間（保持）

法律で期間が定められていない場合、当社はその目的のために必要な期間のみデータを保持し、その後
削除または匿名化します。

| 区分 | 保持 |
|------|------|
| アカウント | 有効な間；アカウント削除後は削除／匿名化（法的な保持義務がある場合を除く） |
| 認証記録 | アカウントが有効な間 |
| エンタイトルメント／ライセンス | ライセンス期間中、およびその後サポートと紛争のための限定的な期間 |
| デバイス／アクティベーション | エンタイトルメントが有効な間；デバイスの削除時またはライセンス終了時に解放 |
| Team メンバーシップ／招待 | Team ライセンスが有効な間；招待は失効します |
| 支払い | ライセンス期間に加え、会計／税務上必要な期間 |
| 返金／紛争／チャージバック | それらの対応と証跡に必要な期間に、会計上の期間を加えたもの |
| 税務／会計記録 | 適用される税法により必要とされる期間（例：最長 7 年） |
| セキュリティログ | セキュリティおよび不正検知に十分な限定的な期間 |
| 管理者監査ログ | 完全性の記録として限定的な期間保持 |
| サポートのやり取り | お客様をサポートするために必要な間、およびその後の限定的な期間 |
| マーケティングの同意 | 同意が有効な間、およびその後証跡として |
| 同意の撤回 | 選択が尊重されたことの証跡として保持 |
| 削除済みアカウントのバックアップ | 削除後、通常のバックアップのローテーションの範囲内で日常的なバックアップから消去 |

## Cookie と広告

ウェブサイトは、機能させるために必須の Cookie のみを使用します。必須でない（広告）Cookie は
**既定でオフ**であり、Cookie バナーまたは **Cookie 設定**からお客様がオプトインした場合にのみ
読み込まれます。当社は Cloudflare Web Analytics を使用しており、これは Cookie を使用せず、
サイトをまたいでお客様を追跡しません。お客様はいつでも選択を変更または撤回できます。

## お客様の権利

お住まいの地域（例えば EU／英国の GDPR や日本の APPI（個人情報保護法））に応じて、お客様には
次の権利がある場合があります：

- 当社が保有するお客様に関する個人データへの**アクセス**
- 不正確なデータの**訂正**
- お客様のデータ（およびアカウント）の**削除**
- 特定の処理の**制限**または処理への**異議**
- **ポータビリティ** — 特定のデータをポータブルな形式で受け取ること
- **同意の撤回**（例：広告計測）をいつでも行うこと。ただし、それ以前の適法な処理には影響しません

これらのいずれかを行使するには、お客様のアカウントのアドレスから **support@bugit.dev** まで
メールでご連絡ください。**アカウントを削除**してお客様のデータを削除することもできます（税務
記録など、法律により当社が保持しなければならない記録を除きます）。当社は、適用される法律で
求められる期間内に対応します。

**苦情。** EEA にお住まいの場合は、お住まいの地域のデータ保護当局に苦情を申し立てることが
できます。英国では Information Commissioner's Office（ico.org.uk）へ、日本では個人情報保護
委員会（ppc.go.jp）へ申し立てることができます。当社としては、まず support@bugit.dev にて
お客様のご懸念を解決する機会をいただけますと幸いです。
