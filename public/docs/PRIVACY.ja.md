本ソフトウェアが収集するもの、および収集しないものについての、平易な言葉による概要です。すべてはお客様自身のマシン上で動作します。

## 本ソフトウェアが Taskivator に送信するもの

BugIt は、お客様のウェブブラウザを通じてアクティベートされます。お客様は BugIt Portalでご自身の BugIt アカウントにサインインし、このデバイスを承認します。入力、貼り付け、または共有する**ライセンスキーはありません**。

ライセンスをアクティベートし、有効に保つために、本ソフトウェアは、お客様の利用資格をこのインストールおよびデバイスに紐付けるために必要な情報 — **ライセンス／アクティベーションデータ** — のみを送信します:

- **インストール識別子** — この BugIt インストールに対して一度だけ作成されるランダムな値です。お客様のハードウェアから導出されるものではなく、お客様を特定するものでもありません。
- **匿名の、一方向でハッシュ化されたデバイスフィンガープリント** — 基本的なマシン属性から導出される 16 文字のハッシュです。これを逆算して、お客様またはお客様のハードウェアを特定することはできません。
- **デバイスラベル** — お客様のコンピューターのホスト名です。これにより、お客様のアカウント内でこのデバイスを識別し、ご希望のときにPortalから削除できます。
- お客様の**オペレーティングシステム名**および **BugIt のバージョン**。互換性、および更新が利用可能かどうかを確認するためのものです。そして
- 短命の**アクティベーション用データ** — サインインを完了するためだけに使用される、一回限りのチャレンジおよび承認トークン、ならびにローカルの確認用シークレットの一方向ハッシュです。シークレットそのものがお客様のマシンから出ることは決してなく、生のチャレンジおよびトークンが保存されることも決してありません。

お客様のアカウントへのサインインは、Portal上のお客様のブラウザで行われます。その見返りとして、Portalはこのデバイスおよびインストールに紐付けられた**署名済みの利用資格**を発行し、本ソフトウェアはこれをローカルで検証します。

これらは BugIt Portalにのみ送信され、お客様のライセンスをアクティベートおよび検証し、お客様のデバイスを管理し、より新しいバージョンが利用可能かどうかを確認する目的にのみ使用されます。お客様が更新をダウンロードする際、Portalは、セキュリティおよび不正利用防止のために、そのダウンロード — リクエストの IP アドレスおよびブラウザのユーザーエージェントを含む — も記録します。

## お客様のデバイスに完全にとどまるもの

- お客様の仕様、用語集、ハウススタイル、および学習された修正
- お客様の `config.json` およびローカルのプロジェクトファイル
- お客様の API トークン（OS の資格情報ストアに保管されます）

これらのいずれも、どこにも送信されません。

## *お客様が*接続するサービスにのみ送信されるもの

チケットを作成して起票するために、お客様の報告テキストは、お客様が使用する AI モデル（GitHub Copilot、またはお客様ご自身の OpenAI／Anthropic キー）、および起票先のトラッカー（Jira や Azure DevOps など）に送信されます。これは**お客様**が選択し、接続した AI およびツールであり、Taskivator を経由したり、Taskivator にコピーされたり、Taskivator に閲覧されたりすることは決してありません。

## 資格情報

API トークンは、お客様のオペレーティングシステムの資格情報ストアに保管されます — ファイルに保存されることはなく、Taskivator に送信されることも決してありません。

## ウェブサイトのアクセス解析

BugIt は、ウェブサイトの全般的なパフォーマンスと訪問数を把握するために Cloudflare Web Analytics を使用します。このサービスは、サイトをまたぐトラッキング Cookie を使用しない設計です。

お客様の許可がある場合、当社は広告が購入につながっているかどうかを把握するために Google Ads の計測も使用することがあります。設定は、Cookie 設定からいつでも管理できます。

購入計測が有効な場合、購入金額、通貨、一意の注文参照などの限定的な取引情報がアトリビューションに使用されることがあります。バグレポートの内容、お支払いカード情報、および BugIt ソフトウェアに入力された情報は、Google Ads と共有されません。

これらの計測ツールは、BugIt のウェブサイトおよびPortalにのみ適用されます。BugIt ソフトウェアは、Google Ads の計測を使用せず、製品テレメトリも送信しません。
